# VERA Model Training — Current Execution Protocol V2

Status: **CURRENT**

This repository keeps its strict public/private, zero-cost, source-grounding, qualification, and no-secret boundaries. Protocol V2 changes only the team's execution discipline around those boundaries.

## Rule

A current specific Patrick instruction or valid current assignment is sufficient for the bounded reversible work it assigns and the minimally necessary reversible setup.

- Class 0 read/inspect/analyze: proceed.
- Class 1 isolated branch, local/test work, issue/PR preparation, bounded training-source changes: proceed from the current assignment; do not demand the same permission again as a lease.
- Class 2 shared mutable work: resolve one writer to prevent collision.
- Class 3 protected or sensitive effect: keep exact gating. In this repository that includes private/sensitive data introduction, credentials/secrets, paid compute/billing, release/deployment, destructive admin, or any external training run/effect whose authority is not already expressly granted.

Writer leases are collision controls. Exact hashes/checksums are reproducibility evidence. Neither should become redundant permission ceremony for already-assigned isolated work.

## Privacy is still a real hard stop

Protocol V2 does **not** make public bootcamp execution suitable for private chat transcripts, secrets, personal data, confidential material, or sensitive identity material. Those remain prohibited in the public/zero-cost mode.

## Qualification is still evidence-bound

A local proxy PASS does not qualify the native identity. The native cold/adversarial/transfer evaluation remains the competence gate.

## Anti-paralysis regression

FAIL if a worker:
- refuses an assigned isolated branch merely because an older generic rule was `LOCAL_ONLY`;
- asks Patrick to restate an already-clear reversible assignment as a maximal lease;
- treats a future protected training/deployment effect as a reason not to perform current safe source/test work;
- explains a permission-recursion mistake but leaves the still-current reversible task undone;
- invents additional blocking gates after stated criteria pass with no unresolved HIGH/MEDIUM defects.

Also FAIL if a worker uses V2 to bypass privacy, cost, source-grounding, or native-qualification boundaries.
